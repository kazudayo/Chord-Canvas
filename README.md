# HarmoTrail — コード進行アシスト

コードを自分で選び、理由を読み、耳で確かめながら作曲するレスポンシブWebアプリです。推薦処理は音楽理論による決定論的なロジックです。AI API・バックエンドは使用していません。

## 起動

Node.js 20以降で実行できます。

```sh
npm install
npm run dev
```

表示されたローカルURLを開いてください。初回は試聴できるサンプル曲を表示します。「マイソング → 新しい曲をつくる」で空の曲から始められます。

「定番進行」から試聴・追加・置換できます。再生バーの「Piano / MIDI」から音源設定を開き、「書き出し」からテキスト・MIDIを保存できます。詳細な改修内容・変更ファイル・検証結果は [IMPLEMENTATION.md](IMPLEMENTATION.md) を参照してください。

```sh
npm test       # 音楽理論・保存データ・書き出しのテスト
npm run build # TypeScript型検査と本番ビルド
npm run preview
```

## ログイン設定

アプリはログイン画面から始まり、認証されるまでコード進行画面を描画しません。認証情報を変更する場合は次を実行し、開発サーバーを再起動します。
初期ユーザーIDは`harmotrail`です。初期パスワードは管理者へ別途共有してください。

```sh
npm run auth:set -- <ユーザーID> <10文字以上のパスワード>
```

ユーザーIDとパスワードそのものは保存せず、SHA-256ハッシュを`.env.local`へ保存します。`.env.local`はGit管理対象外です。本番ビルド環境では`HARMOTRAIL_AUTH_USER_HASH`と`HARMOTRAIL_AUTH_PASSWORD_HASH`をシークレット環境変数として設定してください。ログイン状態はタブの`sessionStorage`に保持され、タブを閉じるか「ログアウト」を押すと失効します。5回失敗すると30秒間ロックします。
GitHub Pagesへ公開する場合は、同名のRepository Secretsを設定するとデプロイ時に使用されます。未設定の場合は初期認証情報が使われます。

重要：このアプリは静的なReactアプリのため、このログインは一般利用者向けの閲覧ゲートです。機密データを守る完全なサーバー認証ではありません。公開URL自体を厳格に保護する場合は、配信サービス側のアクセス制御またはサーバー認証を併用してください。

GitHubリポジトリ名は`HarmoTrail`、GitHub Pagesの公開URLは `https://kazudayo.github.io/HarmoTrail/` を使用します。旧名称で保存した曲・音源設定・ログイン状態は、新しい保存キーへ自動移行します。

## 実装した機能

- 長調・短調、異名同音を考慮した音名表記、三和音・七の和音。短調の自然・和声・旋律短音階を内部で扱い、V・V7・vii°・vii°7を候補に追加。
- 機能進行、終止、根音の5度進行、共通音、声部の最短移動、ベース移動、反復ペナルティを合成した推薦。候補ごとの日本語の理由。
- 借用和音、セカンダリードミナント、代理コード、雰囲気による優先順位変更。
- sus2 / sus4 / add9 / maj9 / m9 / 9 / 11 / 13 / dim7 などを自由なコードダイアログから追加。
- コード追加（選択コード直後）、置換、削除、ドラッグまたは左右ボタンで並び替え、Undo / Redo。
- 全構成音の転回形とスラッシュコード表記、近い配置の提案、鍵盤表示。
- Web Audioによる試聴、Block / Arpeggio再生、BPM、拍数、一時停止と再開、停止、ループ、音量、セクション／曲全体の再生。
- セクション追加・名前変更・削除。最大4コードの接続経路をビーム探索し、上位4経路を提示。接続先の実際の先頭コードを着地点に使用。
- 近親調・平行調・同主調の提案、Pivot Chordの両キーの度数表示、転調経路の試聴と新規セクション作成。
- 全セクションの相対関係・転回形を保つ移調。
- 複数曲のlocalStorage保存、テキスト／Degreeのコピーとテキストファイルのダウンロード。
- PCの3カラム、タブレットの2カラム、スマートフォンの1カラム表示。モーダルのフォーカス管理、操作ラベル、キーボード操作。

## 構成

```text
src/
  music/       音名・調・和音・推薦・声部進行・転調と経路探索
  audio/       共通NoteEvent、サンプルピアノと再生タイムライン
  midi/        Web MIDIデバイス管理、NoteOutput、SMF書き出し
  state/       複数曲保存・Undo/Redo・書き出し
  components/  鍵盤・コード詳細・セクション接続・転調・モーダル
  App.tsx      ワークスペースと編集操作
  styles.css   レスポンシブUI
```

## 音楽上の扱い

機能分類はポピュラー音楽の作曲支援用の近似です。iii・viをトニック系、ii・IVをプレドミナント系、V・vii°をドミナント系として扱います。自然短音階のv・VIIもドミナント系に置きますが、導音のあるV・vii°と同等の終止感を保証するものではありません。コード進行から表示する正格・変格・偽・半終止は、旋律や拍位置を含まない「終止の候補」です。

声部評価は、小さい方の構成音集合を大きい方へ一対一対応させる最小ピッチクラス移動を使用します。転回形提案では実際の配置の音高とベースの移動も比較します。声部の交差や禁則をすべて解決する四声体和声課題ソルバーではありません。再生時は転回形を保つ閉じた配置を、前コードに近いオクターブへ寄せ、1オクターブ下のベースを追加します。テンションの省略は行いません。内蔵ピアノ・外部MIDI・MIDI書き出しは同じNoteEvent生成を使用します。

雰囲気は候補の重み付けであり、感情を保証しません。キーの選択変更は既存のコードの音高を保って再分析します。実際に音高を移す場合はキー欄の移調ボタンを使います。

音名と和音生成は独自実装です。理論の確認に参照した資料：

- [Open Music Theory — Modal Mixture](https://viva.pressbooks.pub/openmusictheory/chapter/modal-mixture/)
- [Open Music Theory — Applied Chords](https://openmusictheory.github.io/appliedChords.html)

## 保存・運用

保存範囲は同じブラウザ・同じオリジン（ホストとポート）です。ブラウザのデータ削除、シークレットモード終了、異なるポートでの起動では保存曲を共有できません。大切な進行はテキスト・MIDIを書き出してください。クラウド同期や音声ファイル書き出し、MIDI読み込みはありません。UIのWebフォントを取得できなくてもシステムフォントで動作します。

再生はユーザーのボタン操作後に開始します。ブラウザがバックグラウンドタブを停止した場合、タイマーや音声再生が制限されることがあります。

## ピアノ・外部MIDI

ピアノはAlexander Holm氏のSalamander Grand Piano録音を21個同梱し、初回再生時にローカルから読み込みます。CC BY 3.0に基づく配布で、[音源クレジット](public/assets/audio/piano/ATTRIBUTION.md) に出典とライセンスを記載しています。

外部MIDIは「Piano → MIDIを使用」でアクセスを有効にしてからSound Sourceを選びます。MIDI Channel（1〜16）、Velocity、Test Note、Refresh MIDI Devices、Panicを利用できます。MIDI非対応・権限拒否・出力なしでも内蔵ピアノとMIDI書き出しは利用できます。localhostまたはHTTPSで起動してください。

MIDIは音声ではなく演奏情報です。DAW側で受信ポート・チャンネル・音源トラックを設定する必要があります。VST / AUをブラウザから直接ロードしません。OSの仮想MIDIポート設定は本アプリから変更しません。

## MIDIファイル

現在セクション／曲全体をSMF Format 0（480 PPQ）で書き出します。テンポ、4/4拍子、セクション名のマーカー、転回形・奏法・拍数・Velocity・選択チャンネルを反映したNote On/Offを含みます。ループは1周分のみです。音源の種類や音量ミキサーはファイルに含めず、DAW側で設定します。
